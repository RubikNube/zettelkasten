# Jira tickets

Create or open a ticket note with `<leader>zj`. Ticket notes use stable Jira keys such as `PROJECT-123.md`.

Neovim reads the Jira site from `JIRA_BASE_URL`, for example:

```sh
export JIRA_BASE_URL="https://company.atlassian.net"
```
