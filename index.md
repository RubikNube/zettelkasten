# Zettelkasten

## Start here

- [[inbox/index|Inbox]]
- [[projects/index|Projects]]
- [[tickets/index|Jira tickets]]
- Open today's daily note with `<leader>zd`.

## Workflow

1. Capture unfinished ideas in the inbox with `<leader>zN`.
2. Refine durable ideas into permanent notes at the vault root with `<leader>zn`.
3. Connect related notes with `[[wiki links]]` and a small number of useful tags.
4. Keep temporary project material under `projects/` and link reusable knowledge back into permanent notes.
5. Create or open Jira ticket notes with `<leader>zj`.
